MongoDB provides a document‑model database platform that can be deployed on any cloud or on‑premises infrastructure. It offers services such as MongoDB Atlas for multi‑cloud data management, vector search, real‑time operational workloads, and tools like Compass for GUI access. The platform is used by developers and enterprises building applications that require scalable, searchable, and AI‑enabled data handling.

**Areas:** Cloud Database · Database · Document Database · NoSQL · MongoDB

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for MongoDB: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
